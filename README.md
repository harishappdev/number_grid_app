# Number Grid

A Flutter application that displays numbers from 1–100 in a dynamic grid layout with highlighting for:

- Odd Numbers
- Even Numbers
- Prime Numbers
- Fibonacci Numbers

## Features

- Dynamic GridView UI
- Pattern-based number highlighting
- Real-time UI updates
- Clean and responsive design

## Technologies Used

- Flutter
- Dart
